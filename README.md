# V2Ray VLESS/VMess/Trojan Server -- Telegram Bot Admin

خادم V2Ray (VLESS / VMess / Trojan عبر WebSocket) تتم إدارته **بالكامل عبر بوت تلقرام**.
لا توجد أي واجهة ويب أو تسجيل دخول -- البوت هو نقطة التحكم الوحيدة، ويعمل حصريًا مع معرف الأدمن المحدد في `TELEGRAM_ADMIN_CHAT_ID`.

## المزايا

- إنشاء تكوينات VLESS / VMess / Trojan من داخل تلقرام (اختيار البروتوكول + مدة صلاحية مستقلة لكل تكوين + حد استهلاك بالجيجابايت).
- عرض/تعديل/حذف التكوينات، مع رابط الاتصال وصورة QR يُرسلان مباشرة في المحادثة.
- عرض حالة الخادم (تشغيل/إيقاف V2Ray، القرص، الذاكرة، عدد العملاء النشطين/المنتهية/الموقوفة).
- تشغيل/إيقاف/إعادة تشغيل V2Ray (بدون انقطاع، عبر تبديل slot A/B) من تلقرام مباشرة.
- عرض آخر سجلات التشغيل.
- أي مستخدم آخر غير الأدمن يُتجاهل تلقائيًا (ما لم يُفعَّل "الوضع العام" أدناه).

### 🌍 الوضع العام (بوت لجميع المستخدمين)
من زر **⚙️ إعدادات البوت العام** في قائمة الأدمن يمكن:
- تفعيل/تعطيل الوضع العام: عند التفعيل يمكن لأي شخص يراسل البوت إنشاء **تكوين VLESS واحد فقط** خاص به (UUID خاص به، ويظهر له فقط تكوينه هو).
- تحديد **مدة صلاحية افتراضية** و **حد بيانات (GB) افتراضي** يُطبَّقان تلقائياً على كل تكوين جديد ينشئه أي مستخدم.
- عرض/حذف تكوينات المستخدمين من نفس القائمة.

عند انتهاء صلاحية تكوين المستخدم يمكنه تجديده بنفسه (زر "🔄 تجديد تكويني") فيحصل على UUID ورابط جديدين بنفس المدة والحد المحددين من الأدمن.

**منع المشاركة:** يحق لكل مستخدم استخدام تكوينه من حتى 3 أجهزة/شبكات مختلفة في نفس الوقت (جهازه + جهازين إضافيين يشاركهما). إذا رصد الخادم اتصالاً من جهاز رابع (عنوان IP رابع مختلف) بينما لا تزال الأجهزة الثلاثة الأخرى نشطة، يتم إيقاف التكوين تلقائياً وإشعار صاحبه عبر البوت، وعليه عندها الضغط على "🔄 تجديد تكويني" للحصول على تكوين جديد.

زر **📖 كيفية التشغيل** المتاح للمستخدمين يشرح كيفية استيراد الرابط/QR داخل تطبيق **Dark Tunnel** وكيفية ضبط حقل **SNI** إلى `youtube.com` لتحسين الاتصال.

## التشغيل محليًا

**المتطلبات:** Node.js 22+, curl, unzip (لتحميل ثنائي V2Ray تلقائيًا)

1. تثبيت الاعتماديات: `npm install`
2. انسخ `.env.example` إلى `.env` واضبط:
   - `APP_URL` — نطاق الخادم العلني (يُستخدم لبناء روابط التكوين)
   - `TELEGRAM_BOT_TOKEN` — توكن بوت تلقرام
   - `TELEGRAM_ADMIN_CHAT_ID` — معرف حساب تلقرام المسموح له وحده بالتحكم
3. تشغيل التطبيق: `npm run dev`
4. من تلقرام: أرسل `/start` للبوت لعرض القائمة الرئيسية.

## النشر عبر Docker

```bash
docker build -t v2ray-bot .
docker run -e TELEGRAM_BOT_TOKEN=... -e TELEGRAM_ADMIN_CHAT_ID=... -e APP_URL=https://your-domain.com \
  --ulimit nofile=65536:65536 \
  -p 3000:3000 -p 10080-10082:10080-10082 -p 10090-10092:10090-10092 v2ray-bot
```

راجع `Dockerfile` و`docker-compose.yml` لمزيد من التفاصيل.

## المزايا الجديدة

- **الأداء عند عدد كبير من المستخدمين:** تمت زيادة عدد الاتصالات المتزامنة المسموح بها بين البوت وتلقرام، وزيادة قائمة الانتظار (backlog) لقبول الاتصالات، وتفعيل `TCP_NODELAY` لكل اتصال، وضبط `GOMAXPROCS` صراحة عند تشغيل V2Ray، ورفع حد عدد الملفات المفتوحة (`ulimit -n`) داخل الحاوية — كل هذا يحسّن سرعة الاتصال واستقراره عندما يتصل آلاف المستخدمين في نفس الوقت.
- **📡 الأجهزة المتصلة (أدمن):** زر/أمر جديد (`/devices`) يعرض عدد الأجهزة المتصلة الآن لكل تكوين، بالإضافة إلى إجمالي الأجهزة المتصلة في "📊 حالة الخادم" وفي تفاصيل كل عميل.
- **🌍 عرض IP والمدينة ومزوّد الخدمة تلقائياً:** بالإضافة لاسم الدولة، يعرض البوت الآن IP الخادم ومدينته ومزوّد خدمته (ISP) تلقائياً في تكوين المستخدم وقائمة العملاء وتفاصيل كل عميل.
